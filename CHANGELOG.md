# Revision history for haskell-to-sqlite

## 0.2.0.0 -- 2026-03-06

* Upgraded frontend from vanilla JavaScript to React.js with Vite
* Added glassmorphism dark theme with smooth animations
* Integrated Chart.js for interactive data visualizations
* Added Dashboard, BasinsPanel, RainfallPanel, RiskCalculator, and ResultsPanel components
* Updated backend to serve React build output from frontend-react/dist
* Added .devcontainer configuration for GitHub Codespaces
* Updated project dependencies in haskell-to-sqlite.cabal

## 0.1.0.0 -- 2026-03-02

* First version. Released on an unsuspecting world.
* Haskell backend with Scotty web framework
* SQLite database with sample basin and rainfall data
* Deterministic flood risk classification using ADTs and pattern matching
* REST API endpoints for basins, rainfall, risk calculation
* Vanilla JavaScript frontend with dark theme
